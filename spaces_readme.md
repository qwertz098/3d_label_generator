# 3D Label Generator

Web-based application for creating customizable 3D labels with CadQuery and Three.js.

## Features

- Customizable label geometry (width, height, thickness, corner radius)
- 9 sans-serif fonts with bold/italic support
- Extruded or subtracted (engraved) text
- Screw hole mounting options (2 or 4 holes)
- Multi-label build plate arrangements
- Interactive 3D preview
- Export to STEP and STL

## Usage

1. Enter your label text
2. Configure dimensions and font
3. Click "Update Preview"
4. Export as STEP or STL
